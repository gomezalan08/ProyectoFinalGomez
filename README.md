# 🛒 ElectroShop - E-commerce React

Proyecto final integrador para el curso de React JS. Es una tienda online de productos tecnológicos (Smartphones, Notebooks, Tablets) con un flujo de compra completo.

## 🚀 Enlace al proyecto en vivo (Deploy)
**[👉 Haz clic aquí para ver la tienda funcionando](https://proyecto-final-gomez-rose.vercel.app/)**

## ✨ Características (Features)
* Catálogo completo de productos traídos desde Firebase.
* Filtrado por categorías usando navegación dinámica.
* Vista de detalle de cada producto.
* Carrito de compras con persistencia de datos y cálculo total.
* Formulario de Checkout que genera una orden de compra en la base de datos.
* Diseño responsivo y moderno con CSS puro.

## 🛠️ Tecnologías utilizadas
* **React JS** (Create React App)
* **React Router DOM** (Navegación y rutas)
* **Firebase / Firestore** (Base de datos NoSQL y almacenamiento en la nube)
* **Context API** (Manejo del estado global del carrito)
* **Vercel** (Hosting y Deploy)
